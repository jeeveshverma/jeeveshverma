### 🧭 About

I'm an SDET focused on **backend quality** — designing scalable test automation and validating the systems behind enterprise search: authentication, permissions, crawling, indexing, and search relevance.

- 🔭 Currently at **Glean**, owning release validation for connectors like GDrive, Notion, Tableau, Greenhouse & Workday — including **MCP (Model Context Protocol)** workflows.
- 📈 Grew connector regression automation coverage from **30% → 98%**, cutting manual validation by a week per release.
- 🐞 Debugged **100+ launch-blocking issues** across feature-flag, config, and environment-specific failures.
- 🤝 Previously scaled API automation and QA strategy at **Birdeye** and **Slice**.
- 💡 I care about making releases faster *and* safer through reusable, well-designed test workflows.
